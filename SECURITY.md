# Security Policy

## Supported Versions

We actively support the latest version of Mamaco Notes. If you find a security issue, please ensure you are running the most recent update before reporting.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please **do not open a public issue**. Instead, report it through one of the following channels:

1.  **GitHub Private Reporting**: Use the "Report a vulnerability" button in the **Security** tab of this repository.
2.  **Email**: Send a detailed description of the issue to `mamaconotes@gmail.com`.

We will acknowledge your report and provide a timeline for a fix as quickly as possible.

# Política de Segurança

## Versões Suportadas

Oferecemos suporte ativo para a versão mais recente do Mamaco Notes. Se você encontrar um problema de segurança, certifique-se de estar usando a atualização mais recente antes de reportar.

| Versão | Suportada          |
| ------ | ------------------ |
| 1.0.x  | :white_check_mark: |
| < 1.0  | :x:                |

## Reportando uma Vulnerabilidade

Se você descobrir uma vulnerabilidade de segurança neste projeto, por favor, **não abra uma issue pública**. Em vez disso, reporte através de um dos seguintes canais:

1.  **GitHub Private Reporting**: Use o botão "Report a vulnerability" na aba **Security** deste repositório.
2.  **E-mail**: Envie uma descrição detalhada do problema para `mamaconotes@gmail.com`.

Nós confirmaremos o recebimento do seu relatório e forneceremos um cronograma para a correção o mais rápido possível.
